## 3. 검증 실행의 회귀가 되돌아왔다

검증 실행에서 **게이트 거절 4 → 9**로 뛰었던 것은, 잘린 표를 이어붙인 조각이
채점 대상 밖(`tail`)으로 들어가 **채점 전멸 폴백을 막았기** 때문이다
(`FIX_10차_20260902.md` §8). 이어붙인 조각을 채점에서 빼 두었다가 앞조각이
살아남았을 때만 되붙이도록 고쳤고, 11차에서 확인됐다.

```
게이트 거절   10차 4  →  검증 9  →  11차 3
총 토큰      2,481,271 → 2,769,043 → 2,548,982   (+11.6% → +2.7%)
LLM 호출        1,743  →     1,792 →     1,688   (10차보다 55회 적다)
```

호출이 10차보다 **줄었다.** 이어붙인 조각을 채점하지 않게 되면서 채점 호출이
예전 수준으로 돌아왔기 때문이다.

## 4. 새 가드가 P-E5 에서 진짜 오류를 잡았다 (3건 중 2건 실제)

11차 P-E5 는 p47 「나. 연도별 수익률 추이」를 옮겼는데 두 행이 어긋난다.

```
                20년      21년      22년      23년      24년
답변 종류A     33.38   18.99    -9.25    35.66   -23.62
원문 종류A     33.38   18.99   -31.08    35.66   -23.62
                                 ↑ -9.25 는 p46 연평균표의 '투자신탁 최근3년' 값

답변 종류C-e  -23.42   36.00   -30.91   -23.33     2.05
원문 종류C-e   33.86   19.33   -30.91    36.00   -23.42
              ↑ 행 전체가 어긋났다 (앞뒤가 뒤집히고 마지막 두 칸은 다른 값)
```

`table_axis_conflicts` 가 이 둘을 정확히 지목했다. **값이 전부 코퍼스에 있는
형태**라 `unsupported_values` 로는 원리상 못 잡는 유형이고, 실제로 이 문항의
`unsupported_values` 는 0이다.

### 남은 하나는 오탐 — 날짜 표기 재작성

```
지적   열 이름 '20년1월1일~20년12월31일' 이 값이 나온 표에는 없습니다
원문   20.01.01~20.12.31
답변   20년 1월 1일 ~ 20년 12월 31일        ← 같은 열을 다르게 적었을 뿐
```

축 판정을 "하나라도 없으면"으로 조인 것이 **날짜 재작성**에 걸렸다. 축 이름을
비교하기 전에 날짜 표기를 정규화하면 없어지는 오탐이다 — 12차 수정 후보로 남긴다.

## 5. 어휘 인용은 5건 중 1~2건만 맞다 — 정밀도 보강이 필요하다

숫자가 없는 서술형 답변에 인용을 붙이는 경로를 새로 넣었고 5건이 붙었다.

| 문항 | 붙은 청크 | 배수 | 판정 |
|---|---|---:|---|
| P-F2 | `R2_KR510902511M#p38#c010` 별첨1(투자전략) | 35.8x | ✅ 정답 |
| P-G0a | `R2_KR510902511M#p3#c010` 요약정보 | 5.1x | △ 부분 — 운용사명은 맞으나 기대는 「관련회사」 이해관계인 |
| P-F1 | `doc31#p11#c001a` 투자자 유의사항 | 3.9x | ❌ **다른 펀드(TDF)의 환매 규칙** |
| P-F5 | `doc31#p11#c002` 준법감시인 문구 | 3.9x | ❌ 무관 |
| P-C4 | `R2_KR510902511M#p3#c010` 요약정보 | 3.0x | ❌ 무관 |

### 왜 사전 재판정과 달랐나

수정 전 9·10차 답변으로 재판정했을 때는 오탐 0건이었다. 그때 **후보를 그 펀드의
문서로 한정**했기 때문이다. 실제 실행의 후보에는 제도 문서가 섞여 있고
(`doc31` 은 디폴트옵션 안내), 거기 상투 문구가 어휘로 걸린다.

배수만으로는 안 갈린다 — 오탐 3.9x 가 부분정답 5.1x 와 붙어 있다.
**대신 깔끔한 축이 하나 보인다.**

```
P-F1 · P-F5   질문이 특정 펀드를 지목했는데  →  doc/procedure 청크를 골랐다
P-F2          질문이 특정 펀드를 지목했고    →  그 펀드의 prospectus 청크를 골랐다
```

지목 펀드가 있으면 어휘 인용을 **투자설명서 계층으로 제한**하면 세 오탐 중 둘이
그대로 걸러진다. 12차 수정 후보다. 급하면 `PENSION_CITE_BY_WORDING=0` 으로 끌 수
있고, 그러면 인용 0건이 5 → 9~10 으로 돌아간다.

> ⚠️ 이 경로가 붙인 인용은 **본문 내용의 근거가 아니라 출처 표시**다. P-F1 은
> 답변 본문에서 "제공된 자료에서 찾을 수 없어 정확한 답변을 드리기 어렵습니다"
> 라고 정직하게 밝힌 뒤 일반론을 적었는데, 거기에 다른 펀드의 규칙이 출처로
> 붙었다. 답변은 정직한데 출처가 틀린 형태라 **인용정확도 지표에서만** 손해다.

## 8. 12차 수정 후보 (우선순위)

1. **어휘 인용을 계층으로 제한** — 지목 펀드가 있으면 투자설명서 청크만.
   §5 의 오탐 3건 중 2건이 이걸로 걸러진다. 변경 폭이 작고 효과가 명확하다

   `20년 1월 1일 ~ 20년 12월 31일` 을 같은 것으로 본다
3. **게이트 출구 분리** — D-C4 형 `한계` 문항. "자료에 없다"와 "그 대상에는
   해당하지 않는다"와 "문서마다 다르다"를 구분해 내보낸다. 셋 중 가장 크고,
   골드셋 채점 기준을 먼저 맞춰야 한다

1·2 는 오탐 정리라 되돌리기 쉽다. 3 은 설계라 따로 한 차수를 쓰는 편이 낫다 —
같이 넣으면 어느 수정이 들었는지 못 가린다.
