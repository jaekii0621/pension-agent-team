# 청킹 결과 육안 검증 시 살펴볼 항목들

**목적**: 청킹 코드는 구조적으로 보장되는 부분과, 사람이 판단해서 하드코딩한 부분이 섞여있음. 후자는 자동 검증으로 못 걸러지므로, 나중에 원본 파일 + 청킹 결과(jsonl)를 같이 대조할 때 아래 항목 위주로 확인할 것.

---

## 1. 자동으로 보장되는 것 (육안 검증 우선순위 낮음)

코드가 구조적으로 처리하기 때문에, 사람이 매번 다시 확인할 필요는 없는 것들:

- 표 병합(가로/세로) 해석 — `resolve_table_grid()`가 gridSpan/vMerge를 기계적으로 처리
- 페이지 경계에서 질문/답변이 안 끊기는지 — 상태유지 파서(`QAParser`)가 문서 전체에 일관 적용
- 청크 필드 형식(chunk_id, source, parse_method 등) — `schema.py`의 `__post_init__` 검증이 매 청크마다 강제

---

## 2. 육안으로 반드시 확인해야 하는 것

### 2-1. 사람이 수동으로 지정한 "예외 표" 목록이 맞는지
장르B의 `FLOWCHART_TABLES`, `CALC_BOX_TABLES`처럼, "이 표는 일반 표가 아니다"를 코드에 **하드코딩된 (문서ID, 표번호)** 로 지정해둔 부분이 있음. 표 번호를 사람이 눈대중으로 잘못 짚으면(실제 사례: doc52 계산박스를 표1로 잘못 지정, 실제는 표2였음) 코드는 에러 없이 조용히 잘못된 결과를 만듦.

**확인 방법**: 원본 파일을 열어서 표 순서를 직접 세어보고, 코드에 하드코딩된 표 번호와 일치하는지 대조.

**해당 대상**:
- 장르B: doc23(흐름도 표), doc39·doc52(계산박스 표)

### 2-2. 수식/계산식이 원문 그대로 보존됐는지
÷, ×, −, ± 같은 특수기호나 괄호 구조가 복사·변환 과정에서 깨지지 않았는지 원문과 글자 단위로 대조.

**해당 대상**:
- doc39: 연금수령한도 계산식 (÷, × 포함)
- doc52: 근속연수공제·환산급여공제 계산식

### 2-3. 문서 간에 서로 연결된 수식/개념이 있는지
하나의 장르, 하나의 문서만 보고 청킹하기 때문에, **여러 문서에 걸쳐 반복되거나 연결되는 공식**은 장르별 작업만으로는 놓칠 수 있음. 전체 장르가 다 청킹된 뒤, 사람이 교차 확인해야 함.

**확인이 필요하다고 알고 있던 연결점** (예전 메모 기준, 실제 존재 여부 및 정합성 재확인 필요):
- 연금수령한도 공식 — doc1, doc2, doc21, doc22, doc39에 걸쳐 등장 가능성
- ISA 관련 MIN() 공식 — doc4, doc6, doc23
- ISA 전환 공식 — doc33, doc4, doc6

### 2-4. 문단 청킹이 애매한 지점에서 끊겼는지
문단 그룹핑 기준(`looks_like_heading()`)은 "20자 이하 + 문장부호로 안 끝남" 같은 어림짐작 규칙이라, 실제 소제목이 아닌데 소제목으로 오인되어 문맥이 부자연스럽게 끊겼을 수 있음.

**확인 방법**: 청크 길이가 유난히 짧은(300자 미만) `paragraph` 타입 청크들을 우선적으로 훑어보고, 앞뒤 청크와 이어 읽었을 때 문맥이 자연스러운지 확인.

## 3. 장르별 체크 우선순위 (지금까지 작업 기준)

| 장르 | 확인 1순위 | 이유 |
|---|---|---|
| B | doc39, doc52 | 수식 존재 + 표 번호 하드코딩 |
| B | doc23 | 흐름도 표 스킵 처리가 맞는지 |
| A | doc16 | "○"가 질문이 아니라 표 제목으로도 쓰인 특이 케이스 |
| C | doc49, doc50 | 하위유형 필드가 정확히 매핑됐는지 |

---

## 4. 검증 진행 방식 제안

1. 위 "1순위" 문서부터 원본 파일 + 해당 문서의 청크만 뽑아서 나란히 대조
2. 하드코딩된 예외 표 번호 목록(`FLOWCHART_TABLES`, `CALC_BOX_TABLES` 등)을 원본과 대조해 표 번호가 정확한지 우선 확인
3. 전체 장르 청킹이 다 끝난 뒤, 2-3(문서 간 연결 수식)은 별도로 한 번에 몰아서 확인
4. 문제 발견 시 → 코드 수정 → 해당 장르 전체 재실행(하나 고치면 그 장르 전체에 자동 재적용됨)
