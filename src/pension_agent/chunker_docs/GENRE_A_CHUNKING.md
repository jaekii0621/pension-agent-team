# 장르A 청킹 로직 정리

**대상**: 제도 Q&A 8개 (doc10, 12, 13, 14, 15, 16, 17, 18)
**입력**: `parse_genre_a.py` 결과(문제A/B 수정판) — 텍스트, 표(페이지경계 병합·질문매칭 완료)
**청킹 코드**: `build_chunks_genre_a.py`
**결과물**: `chunks_genre_a.jsonl` (90개 청크)

---

## 1. 청크 구조

문서 하나당 **Q&A 청크 여러 개 + 법령조문 청크 여러 개**로 구성.

| 청크 종류 | 개수(전체) | source | distractor |
|---|---|---|---|
| Q&A (질문+답변, 표 있으면 붙임) | 53개 | "제도" | False |
| 첨부 관련법령 조문 (조 단위) | 37개 | "제도" | True |

- `ChunkA(Chunk)` — `schema.py`의 `Chunk`를 상속, `distractor: bool` 필드만 추가
- `distractor=True`는 "법령 원문이라 질문과 무관하게 검색에 낚여 들어올 수 있음"을 표시하는 용도 (검색 필터링/후처리 때 참고)

### Q&A 청크 예시
```
Q: 퇴직연금이 무엇인가요?
A: 퇴직연금은 기업이 근로자의 퇴직금을 사외 금융기관에 적립하고, 퇴직 시 근로자가 연금(만 55세 이후 지급) 또는 일시금으로 수령할 수 있는 노후 소득 보장 제도입니다.
```

### 법령 청크 예시
```
근로자퇴직급여 보장법 제2조(정의) 이법에서 사용하는 용어의 뜻은 다음과 같다. 1."근로자"란 근로기준법 제2조제1항제1호에 따른 근로자를 말한다.
```

## 2. 핵심 설계 — "표 영역 제외 후 순수 텍스트 재구성"

`pdfplumber`의 `extract_text()`를 그대로 쓰면 표 안의 셀 텍스트가 답변 본문에 뒤섞여서 나옴(예: "근로시간 계속근로기간 1주일 평균..."이 문장 사이에 끼어듦).

**해결**: `extract_words()`로 단어 단위를 가져온 뒤, 이미 파악된 표의 bbox(top~bottom) 범위에 속하는 단어는 전부 제외하고 순수 문장만 재구성. 표 내용은 `find_tables()`로 별도 추출한 걸 답변 끝에 깔끔하게 붙임.

## 3. 발견하고 고친 버그 3개

### 버그 1 — 법령 조문이 "보"/"장법"으로 쪼개짐
정규식이 "근로자퇴직급여 **보장법**"의 "**장법**" 부분에서 또 한 번 매칭돼서, 조문이 두 조각으로 잘림. `(?<![가-힣])`(매칭 시작 지점 앞이 한글이면 안 됨) 조건 추가로 해결.

### 버그 2 — 법령 인용문 앞에 이전 문장 꼬리가 붙음
원본 PDF 자체에 "...조치를 하지 아니한 **사용자**근로자퇴직급여 보장법 제19조..."처럼 띄어쓰기 없이 붙어있는 경우 발견(doc13, doc16). 코드 문제가 아니라 원본 특성. 알려진 법령명 접두어("근로자퇴직급여", "민사집행법", "근로기준법") 시작 지점부터 잘라내는 후처리로 정리.

### 버그 3 — ⚠️ 페이지 넘어가면 질문이 통째로 사라짐 (가장 심각)
**doc10의 7번째 질문**("다른 법에 따라 퇴직급여를 받는 사람도...")이 페이지2에 있었는데, 파서가 페이지마다 새로 시작하면서 "질문 리스트 이후"라는 상태를 못 이어받아 페이지2 전체를 스킵해버림. `QAParser` 클래스로 바꿔서 상태(현재 어떤 질문을 파싱 중인지)를 페이지 경계 넘어서도 유지하도록 수정 → 8개 문서 전부 질문 개수가 원본과 일치하는지 재검증 완료.

---

## 4. 알려진 특이사항 (버그 아님)

- **doc16에 질문이 9개가 아니라 10개로 잡힘**: 원본 문서가 "○" 기호를 질문 표시뿐 아니라 표 제목("○ 퇴직급여와 압류_요약표")에도 재사용함. 10번째 청크는 실제 질문이 아니라 요약표 캡션 — 내용 자체는 유용하니 그대로 뒀지만 "Q:"로 시작하는 게 어색함. 필요하면 나중에 손으로 라벨만 수정 가능.
- **300~800자 권장 범위 벗어난 청크 65개/90개**: 대부분 원래 답변 자체가 한두 문장으로 짧은 FAQ라서 그렇고, schema.py는 경고만 할 뿐 막지 않음.
